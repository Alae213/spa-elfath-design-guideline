An icon is a word in a shared vocabulary, not a decoration. Every glyph in this guide comes from a single set, drawn on the same grid, with the same stroke — so a settings gear never looks like it was borrowed from another product.

<SectionHeading id="set" number="01" title="The Approved Set" />

The approved set is HugeIcons (free): stroke glyphs on a 24-pixel grid, drawn for interfaces. The seventeen below are the set in use in this guide — each one marks its section, and no other glyph may mark these meanings:

<SectionHeading id="sizes" number="02" title="Sizes & Stroke" />

Three sizes cover every context. The glyph itself never changes — only the box it ships in:

<IconCell name="Touch01Icon" size={16} usage="16 — inline with text and table rows." />
<IconCell name="Touch01Icon" size={20} usage="20 — the default for buttons and nav." />
<IconCell name="Touch01Icon" size={24} usage="24 — feature and empty-state moments." />

</IconGrid>

<div className="not-prose mt-3 border-y border-[var(--hig-border)] py-3">

<p className="text-[13px] leading-6 text-[var(--apple-text)]"><span className="font-semibold">Stroke 1.5, always.</span> Every glyph renders at <span className="font-mono">strokeWidth 1.5</span> on its 24-pixel grid — the weight that reads at 16 and stays light at 24.</p>

<p className="mt-3 text-[13px] leading-6 text-[var(--apple-text)]"><span className="font-semibold">12 is a separator, not a size.</span> The single exception is dense inline separators such as breadcrumb chevrons at 12 — never an interactive glyph, never a meaning-carrier.</p>

<p className="mt-3 text-[13px] leading-6 text-[var(--apple-text)]"><span className="font-semibold">The 44 belongs to the parent.</span> Glyphs stay 16/20/24; the tappable 44×44 minimum lives on the button or row that carries them.</p>

</div>

<SectionHeading id="color" number="03" title="Color & Context" />

Icons have no color of their own. Every glyph renders in <span className="font-mono">currentColor</span> and inherits the text color of its context — the same glyph below, three contexts, zero recoloring:
