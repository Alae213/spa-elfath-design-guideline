Le logo est le visage du groupe : un wordmark dessiné qui fusionne le nom arabe «الفتح» et le latin «SPA elFath» dans un seul assemblage en deux bleus fixes. Les règles de cette référence sont contraignantes sur tous les supports, et le logo est toujours montré dans ses couleurs officielles sur fond blanc — le thème (sombre/clair) ne le modifie jamais sur aucune page de ce guide.

<SectionHeading id="present" number="01" title="Le logo" />

L'assemblage horizontal est le défaut pour le web, les applications et la correspondance. Il est tiré uniquement du fichier maître officiel, jamais redessiné en typographie :
